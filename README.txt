Este sitio es estático y está preparado para publicarse en GitHub Pages o Netlify.

Para GitHub Pages:
1. Crea un repositorio público en GitHub.
2. Sube index.html y .nojekyll.
3. En Settings > Pages, selecciona Deploy from a branch.
4. Selecciona la rama main y la carpeta / (root).
5. GitHub publicará el sitio en una URL github.io.

Para Netlify:
1. Entra a Netlify Drop.
2. Arrastra esta carpeta (o el ZIP).
3. Netlify generará una URL pública netlify.app.
